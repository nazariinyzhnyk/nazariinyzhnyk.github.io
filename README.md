# nazariinyzhnyk.github.io

Personal page — a single-page, terminal-flavoured site. Plain HTML/CSS/JS, no build step.

- `index.html` — the page (content is static HTML; JS only adds the boot intro, matrix rain and small live details like the clock)
- `assets/css/main.css`, `assets/js/main.js` — styles and behaviour
- `assets/img/` — avatar (used for link previews) and its 1-bit green dithered version shown on the page
- `favicon.*`, `apple-touch-icon.png` — pixel-art space invader
- `404.html` — redirects back home

Run locally: `python3 -m http.server 8000` and open http://localhost:8000.
